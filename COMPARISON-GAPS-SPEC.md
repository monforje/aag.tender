## 1. Таблица

### §1.1 — Строка «Показано»
- **Функция:** сумма основного показателя по видимому срезу; появляется только при активном фильтре.
- **Визуал:** узловой уровень — подчинённая строка внутри секции: без заливки, кегль 12/16, secondary, левый отступ 34px (под шеврон секции); глобальный уровень — строка с тихой заливкой `--cu-fill-subtle` над «Итого КП». Порядок фиксирован: Показано → Итог.
- **Поведение:** без фильтра строк нет вовсе; суммы пересчитываются мгновенно от `filters`.
- **Продакшн:** `pages/tender/ui/TenderCompare.tsx` — узловая строка в блоке секции после `rows.map`; глобальная — перед `<TotalRow grand>`; суммы — `filterRows()` × `cellValue()` (та же формула, что у TotalRow). Зависимости: `entities/comparison/model/filters.ts`.

### §1.2 — Узел без видимых позиций не исчезает *(согласовано)*
- **Функция:** карта документа стабильна под любым фильтром.
- **Визуал:** узловой «Показано: 0 позиций» + прочерки вместо сумм (не 0 ₽).
- **Продакшн:** убрать ранний `return null` для пустой группы в `TenderCompare.tsx` (`rowsOfGroup`); итог остаётся `allRowsOfGroup`. Проверка — `comparison.check.ts` (кейс пустого узла).

### §1.3 — Линия отсечки и сворачиваемый хвост *(вид устроил; иконки/анимация из ДС)*
- **Функция:** разметить набор по порогу ключевых (По весу) или высокого разброса (По разбросу); новых порогов нет.
- **Визуал:** линия — `border-top: 2px solid var(--cu-content-secondary)` во всю ширину, подпись охвата 11px; хвост — полоса на `--cu-fill-subtle`, caret-глиф из `shared/ui/Icon/icon-map`.
- **Поведение:** hover хвоста — фон `--cu-state-hover`, шеврон доворачивается на 90° рецептом 11 (transform svg, `.2s standard`); раскрытие мгновенное (каталог запрещает анимацию раскрытия дерева). Нумерация продолжается.
- **Продакшн:** плоские ветви `TenderCompare.tsx`; новые компоненты рядом с `CompareRow` (CutLine/TailRow); пороги — `thresholds.ts`, накопительная доля — `calc.ts`.

### §1.4 — Исходный раздел хлебными крошками *(решение: breadcrumbs)*
- **Функция:** контекст раздела в плоских видах.
- **Визуал:** отдельная строка над названием: сегменты-ссылки 11px tertiary c hover-таблеткой рецепта 1, разделитель `›` цвета placeholder; ниже — titlerow (имя + полоса вклада). Левый край всех элементов = паддинг ячейки; имя режется ellipsis, полоса не поднимает строку.
- **Поведение:** клики по сегментам — навигация по разделам (в перспективе фильтр по узлу); при глубине >2 показываются последние два звена, полный путь в паспорте (§4.1).
- **Продакшн:** `CompareRow.tsx` title-cell; данные `position.sectionPath`; паттерн крошек проекта (Breadcrumbs, каталог состояний рецепт 1).

### §1.5 — Контрол «Сортировка» *(согласовано)*
- **Функция:** единственный владелец порядка строк; дефолт «по разделам» — состояние, не пункт.
- **Продакшн:** `CompareToolbar.tsx` — переименовать cap в «Сортировка:», крестик сброса; `view.ts` — `RowViewId`: убрать 'sections' из выбора, добавить `'spread'`; сброс возвращает дефолт и не трогает filters/potential. Пресеты пересматриваются в §3.2.

### §1.6 — Столбец «Потенциал» *(добавляем + feedback появления)*
- **Функция:** строчный потенциал числом в левой зоне; носитель сортировки «По потенциалу».
- **Визуал:** пятая колонка правее «Разброса»; заголовок с ↓ при активной сортировке; значение right-aligned tabular; попап-разбор (максимум / типично / по подрядчикам) как в демо.
- **Поведение:** появление — шапка вспыхивает инфо-тоном (`.thnew`, 1.8s), ячейки въезжают слева каскадом (`.colenter`, delay 40мс×строка, transform-only, reduced-motion гасит). Снятие галочки мгновенное. Сортировка включает галочку и не выключает.
- **Продакшн:** `view.ts` SatelliteId+'potential'; `TenderCompare.tsx` colgroup/thead/rows + ширина в `model/columns.ts` (пол 120px, входит в leadWidth → пересчёт шапок секций); попап — CellPopup bind; данные — `calc.ts` потенциалы строки.

### §1.7 — «Объём» всегда шаблонный *(согласовано)*
- **Продакшн:** `CompareRow.tsx` — удалить ветку `qtyOrig→qty` в столбце; применённый объём живёт в BidCell ставкой с меткой базы и в попапе ⚠ парой значений.

### §1.8 — Разброс: три степени одной иконкой *(решение владельца)*
- **Функция:** степень разброса читается мгновенно, без чтения слов.
- **Визуал:** глиф SpreadMark один, переведён на currentColor; тон = состояние: low `--cu-tone-success` · noticeable `--cu-tone-warning` · high `--cu-tone-danger`. Размер ×1.2 → 29×19px у всех трёх. Словесных подписей нет; процент остаётся текстом (цвет — не единственный канал).
- **Поведение:** точка линейки скользит ±3px (dotslide 2.4s alternate, transform-only); reduced-motion гасит глобальным правилом; high сохраняет попап-разбор MIN/медиана/MAX/полоску.
- **Продакшн:** `assets/SpreadMark.tsx` — stroke/currentColor + проп tone; `SpreadCell.tsx` — классы `.spreadv .sp-*`; заметная строка сохраняет мягкую заливку ячейки.
