# design-sync: заметки по этому репозиторию

## Форма источника

- Storybook нет → `shape: package`. Пакетный менеджер **bun** (`bun install --frozen-lockfile`).
- Репозиторий — ПРИЛОЖЕНИЕ, а не библиотека. Поэтому для синка добавлены:
  - `src/ds-entry.ts` — публичная точка дизайн-системы (реэкспорт всех слайсов,
    импорты РЕЛЯТИВНЫЕ: ts-morph конвертера собирает свой TS-проект без `paths`);
  - `vite.lib.config.ts` + скрипт `bun run build:ds` → `ds-dist/index.js` + `ds-dist/style.css`;
  - `"types": "./src/ds-entry.ts"` в package.json — по нему конвертер находит список экспортов.
- **Собирать дизайн-систему обязан ТОТ ЖЕ Vite, что и приложение.** Классы в
  `.module.css` названы по эталону (`.row__title`), а в TSX читаются камелом
  (`s.rowTitle`) — это `localsConvention: 'camelCaseOnly'`. esbuild, которым
  конвертер собрал бы исходники напрямую, такого не умеет: молча отдаст
  `undefined` вместо класса, и всё приедет без стилей.
- `src/app/styles/global.css` (токены, reset, каталог состояний) импортируется
  ПЕРВЫМ прямо в `ds-entry.ts` — иначе он не попадёт в `ds-dist/style.css`.
  `cfg.tokensGlob` тут не работает: `copyTokens()` умеет только `tokensPkg`
  (пакет в node_modules), а токены лежат в исходниках.

## Разовая настройка на свежем клоне

```sh
ln -sfn ../src node_modules/@
```

Симлинк нужен ts-morph конвертера: он резолвит `@/shared/ui/Badge` как
`node_modules/@/shared/ui/Badge`. Без него типы, приходящие через алиас
(`Tone`, `IconName`, `GapIndex`, `DayState`), схлопываются в `any`, и
`<Name>.d.ts` теряет контракт. Симлинк в `.gitignore` (node_modules) —
пересоздавать после каждого клона.

Плюс, как обычно: `cp -r <skill>/… .ds-sync/`, `npm i esbuild ts-morph @types/react`
в `.ds-sync/` и `npm i playwright@1.58.0` (см. ниже).

## Playwright

В кэше `~/.cache/ms-playwright` лежит **chromium-1208** — его пинит
**playwright 1.58.0**. Ставить именно эту версию: свежая (1.62) пинит 1234 и
падает с `Executable doesn't exist`. Загрузка браузера не нужна.

## Известные предупреждения валидатора (не чинить)

- `[TOKENS_MISSING] --stack-gap, --inline-gap, --grid-gap, --grid-row-gap,
  --group-gap, --text-leading` — эти переменные компоненты `Stack`/`Inline`/
  `Grid`/`ButtonGroup`/`Text` кладут ИНЛАЙНОВЫМ стилем в рантайме
  (`gapStyle('--inline-gap', gap)`), в статических стилях их и не должно быть.

## Найдено синком в самих компонентах

- **`Checkbox` и `Radio` не прятали нативный инпут.** В модулях есть
  `.input:checked + .box`, но самого правила `.input { position:absolute;
  opacity:0 }` не было — на экране рисовались ДВА контрола, нативный и свой.
  Не всплывало раньше потому, что у обоих нет ни одного потребителя в экранах
  (см. «Что осталось нерешённым» в COMPONENTS.md). Правило добавлено в
  `Checkbox.module.css` и `Radio.module.css`, `.label` получил
  `position: relative`.

## Как писать превью в этом репозитории

- Импорт — из `'clickup-shell'` (имя пакета), оно шимится на `window.AagTender`.
- **Брать настоящие данные домена, а не выдумывать**: `ROWS`, `STATUS`,
  `STATUS_IDS`, `BID_STATUS`, `MOCK_COMPARISON`, `PRESETS`, `SCENARIOS` —
  всё это экспортируется бандлом.
- Имена иконок — только из `icon-map.ts` (`activity`, `checkCircle`,
  `closeCircle`, `documentText`, `clock`, `star`, `flag`, `layers`, …).
  Незнакомое имя роняет ячейку в пустоту без ошибки в логе.
- Ширина карточки в захвате ≈ 650px. Что шире — либо ужимать композицию,
  либо `cfg.overrides.<Name>.cardMode = "column"` (так сделано для `Table`).

## Гоча́ превью (стоили итерации — не наступать снова)

- **Полная `package-build.mjs` стирает `ds-bundle/_screenshots`.** Захват делать
  ПОСЛЕ финальной пересборки волны, иначе листы исчезнут до оценки.
  Правку одного превью гнать через `lib/preview-rebuild.mjs --components …`.
- **Меню и поповеры падают ПРАВЫМ краем от правого края триггера** (`--pop-right`,
  ширина 232px) и влево не переворачиваются. Триггер у левого края → панель
  вылезает за вьюпорт и обрезается. В превью триггер ставится в хвост полосы,
  как и на экране.
- **`SearchInput variant="capsule"` объявлен `flex: 1 1 220px`.** В колонке
  (`<Stack>`) эти 220px становятся ВЫСОТОЙ и капсула раздувается в эллипс.
  Ей нужен ряд — `<Inline>`.
- **`Flyout` — `position: fixed` относительно рейла.** В карточке рейла нет,
  поэтому контейнер получает `transform: translateZ(0)`: он делается
  containing block, и панель встаёт внутри карточки.
- **`TenderPage` читает `:id` из маршрута.** Свой `<MemoryRouter>` поднять
  нельзя (обёртка уже роутер, вложенный роняет react-router) — адрес ставится
  навигацией `useNavigate()` внутри существующего роутера, экран монтируется
  через `<Route path="/tenders/registry/:id">`. Ради этого `ds-entry.ts`
  реэкспортирует `Route`, `Routes`, `useNavigate` (все трое исключены из
  компонентов через `componentSrcMap: null`).
- **`Tooltip` вытаскивается ФОКУСОМ** (`ref.focus()` в эффекте) — пузырь
  показывается и по наведению, и по фокусу.
- **`TreeToggle` статикой не показать.** Стрелка `display:none` до
  `.tree-node:hover`; `display:none` не фокусируется, значит `:focus-within`
  тоже не помогает. Карточка честно показывает структуру узла и называет
  ограничение.
- **`InlineInput` не рисует свой `label`** — он уходит в `aria-label`. Видимую
  подпись ставит потребитель (так же в сводке тендера).
- **У `TreeToggle` проп `label` — БЕЗ глагола**: «Свернуть»/«Раскрыть»
  компонент подставляет сам, иначе получается «Свернуть Свернуть портфели».

## Замечено, но НЕ тронуто (решение за владельцем)

- **`ColorPicker` использует нативный `<select>`** для переключения HEX/RGB/HSL.
  CLAUDE.md запрещает нативный `<select>` в панели ровно по этой причине
  («раскрытый список рисует ОС»). Геометрия взята у shadcn/ui color-picker
  вместе с этим селектом. Заменить на `<Select>` проекта — отдельная задача.
- **Ссылка в покое не отличается от текста**: `Link` не красит и не подчёркивает,
  отличие приходит только по наведению (рецепт 1 каталога состояний). Для
  ссылок ВНУТРИ абзаца это спорно с точки зрения доступности.

## Известные предупреждения валидатора (продолжение)

- **`[RENDER_THIN] … rendered height is 0px` на 86 из 88 карточек.** Артефакт
  ЗАМЕРА, а не рендера: `maxHeight: 0` при `pngBytes` в десятки килобайт и
  непустом `texts[]`. Контрольные листы (`_screenshots/contact-sheet-*.png`)
  показывают живое содержимое у каждой карточки. Не чинить.
- `[GRID_OVERFLOW]` разобран: 25 компонентов получили `cfg.overrides.<Name>` —
  `cardMode: "column"` (широкие: формы, полосы, страницы) или
  `cardMode: "single"` + `primaryStory` (оверлеи: Modal, Drawer, Popover,
  ConfirmDialog, Tooltip, AiDock, Flyout, TenderPage). После этого
  render check: 88/88 чисто.
